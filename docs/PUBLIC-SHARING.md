## Security and verification

Source, actual staged blobs and all history intended for publication were scanned using Gitleaks and targeted identifier/network/path/configuration inspection. Original histories were preserved locally and never uploaded. Credentials, authentication state, real records, databases/logs, model assets, notebooks, unreviewed images and office documents were excluded. The two included PNGs contain synthetic UI only, have exact hash receipts and contain no text/EXIF metadata. Font and Chart.js notices are retained.

Commit/push hooks fail closed without the scanner and reject unsafe artifacts. Destination checks require the exact reviewed HTTPS owner/repository and recorded visibility; PUBLIC is allowed only with explicit approval recorded as true. Tests cover accepted private/public destinations and rejected approval, owner, URL and visibility mismatches. Scanners supplement manual review and cannot prove the absence of every confidential detail.

Existing synthetic tests, isolated smoke checks, UI builds and syntax checks are reported in the project verification documents. No real emails, calls, paid services, customer automations or heavy model benchmarks were triggered for publication.
